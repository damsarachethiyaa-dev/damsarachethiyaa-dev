## Projects

### [Traders Journal](https://github.com/damsarachethiyaa-dev/Traders-Journal) — Desktop trading analytics workstation with MT5 sync
Electron + Node.js desktop app. Ingests closed trades and positions in real-time via custom MQL5 Expert Advisor over localhost. 100% private, offline, with equity curves, performance radar, daily PnL calendar, and KING Edition risk management.

### [Orbit Media Studio](https://github.com/damsarachethiyaa-dev/orbit-media-studio) — Galaxy-inspired desktop media workspace
TypeScript + Electron application. Smart multi-source video/audio downloader, multi-threaded batch queue, and custom watermark studio with hardware acceleration.

### [Daybook](https://github.com/damsarachethiyaa-dev/Daybook) — Minimalist trading journal & economic calendar
Electron + React 18 + TypeScript + Tailwind CSS desktop app. Built-in ForexFactory economic calendar feed, atomic local JSON persistence, streak tracking, and customizable accent themes.

### [Refora Technologies](https://github.com/refora-technologies)
Products built under Refora — Traders Journal, Orbit Media Studio, Pulse Monitor, PixelForge, BatchFlow, AutofillPro.
