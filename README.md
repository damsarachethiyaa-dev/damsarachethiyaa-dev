### 🚀 Featured Projects

#### 📈 [Traders Journal (KING Edition)](https://github.com/damsarachethiyaa-dev/Traders-Journal)
*Privacy-first Windows desktop trading analytics app with direct MetaTrader 5 real-time synchronization.*  
- Ingests closed deals and open positions in real time via custom MQL5 Expert Advisor over localhost.  
- 100% private, offline, with interactive equity curves, performance radar, daily PnL calendar, and KING Edition risk management.  
`Electron` · `Node.js` · `MQL5` · `Tailwind CSS` · `NSIS Installer`

#### 🌌 [Orbit Media Studio](https://github.com/damsarachethiyaa-dev/orbit-media-studio)
*Galaxy-inspired media workspace with a responsive web dashboard and installable PWA.*  
- Smart automatic multi-platform video downloading, 192kbps audio extraction, and batch queues.  
- Region-based watermark removal and blurring studio powered by GPU-accelerated FFmpeg.  
`Next.js 15` · `TypeScript` · `Tailwind CSS` · `FFmpeg` · `Docker`

#### 📒 [Daybook](https://github.com/damsarachethiyaa-dev/Daybook)
*Minimalist desktop trading journal with ForexFactory high-impact economic news integration.*  
- Color-coded profit/loss calendar grid, atomic local JSON persistence, and streak fire animations.  
- Real-time high-impact news badges with local timezone automatic alignment.  
`Electron` · `React 18` · `TypeScript` · `Tailwind CSS`

#### 📸 [ScreenToChatGPT](https://github.com/damsarachethiyaa-dev/Screen-Capture)
*Instant multi-monitor screenshot capture tool with visual AI inspection.*  
- Global hotkey `Ctrl + Alt + G` captures all screens and injects them directly into the Windows ChatGPT desktop application.  
- Built-in prompt presets for order flow reading, key levels, and code debugging.  
`Python` · `OpenAI GPT-4o` · `PyWin32` · `PyInstaller`

#### 🛒 [POS & Inventory Management System](https://github.com/damsarachethiyaa-dev/POS-Inventory-Management-System)
*Modern desktop Point of Sale & Inventory Management System with real-time stock deduction and dynamic JasperReports PDF generation.*  
- High-speed retail checkout, automated invoice tracking, and customer relationship management over MySQL.  
- Built-in JasperReports engine for instant customer summaries, sales logs, and thermal invoice PDFs.  
- Styled with modern FlatLaf dark theme, responsive component layout, and custom UI components.  
`Java` · `Swing` · `FlatLaf` · `JasperReports` · `MySQL` · `Apache Ant`

#### 🏢 [Refora Technologies](https://github.com/refora-technologies)
*Products built under Refora — Traders Journal, Orbit Media Studio, Daybook, ScreenToChatGPT, Pulse Monitor, AutofillPro.*
